# The Investigator

The Investigator is an evolving AI‑powered security and networking analyst built across an eight‑week development track. Each week adds a new capability — from phishing triage to log auditing, network hunting, autonomous agents, and finally a deployed Streamlit SOC Copilot running live on the internet.

This repository contains the Investigator’s “brain”: the instruction set that grows week by week, along with supporting code, tools, and deployment artifacts.

## Skills 
- Week 1: Thinks like a security analyst (prompt library)
- Week 2: can triage suspicious emails — check headers
    (SPF/DKIM/DMARC, Reply-To), flag urgency/secrecy/authority,
    recommend out-of-band verification.
- Week 3: Log Auditing
- Week 4: drive AI through a full investigation — chain its tools across stages, and verify every finding against the raw evidence before you act on it.
- Week 5: stop driving the AI by hand. Wire a local model into a pipeline that triages every new piece of evidence on its own — then verify the report it produced on its own.
- Week 6: wrap your work into one app with a real UI and a live AI model — then point it at multiple telemetry sources at once and hold its verdict accountable. This is threat hunting.
- Week 7: connect the front end to the back end and ship the whole thing to a public URL — push code, and it deploys itself.
- Week 8: Turned the Investigator from a tool you operate into an agent that decides its own steps — learn to supervise it — and package it so it runs anywhere.
